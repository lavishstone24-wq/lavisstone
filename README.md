# Lavish Stone

> Premium Decorative Stones, Landscaping Stones, Pebbles & Garden Stones

Official website and digital catalog for **Lavish Stone Materials** — manufacturer and global exporter of high-grade natural pebbles, river stones, and landscape aggregates.

## Tech Stack
- **Framework**: Next.js 15 (App Router)
- **UI & Styling**: React 19, Tailwind CSS, Lucide Icons
- **Email Delivery**: Resend API
- **Language**: TypeScript

## Getting Started

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Configure environment:**
   Copy `.env.example` to `.env.local` and add your Resend API key:
   ```bash
   cp .env.example .env.local
   ```

3. **Start local dev server:**
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) or [http://192.168.1.4:3000](http://192.168.1.4:3000).
